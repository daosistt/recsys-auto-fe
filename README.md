# RecSys AutoFE

Автоматическая генерация и отбор признаков для рекомендательной системы на MINDsmall.
Генератор строит кандидатные признаки из истории взаимодействий, а алгоритм,
вдохновлённый многорукими бандитами, распределяет бюджет их оценки.
Качество оценивается по nDCG@10 с временным разбиением данных; модель — CatBoost.

Подробное описание метода, экспериментов и ограничений — в [отчёте](report/).

Обученные модели уже сохранены в [artifacts/](artifacts/). После установки
зависимостей и подготовки данных можно просто выполнить
[ноутбук](experiments.ipynb): по умолчанию он показывает сохранённые результаты
без повторного обучения (флаги `RUN_*` выключены).

## Содержимое

- [experiments.ipynb](experiments.ipynb) — отбор признаков, сравнение на dev,
  график случайных подмножеств и проверка на пяти сидах.
- [src/](src/) — подготовка данных, признаки, отбор и метрики.
- [artifacts/](artifacts/) — сохранённые модели v1 и AutoFE.
- [Результаты экспериментов](artifacts/auto_features_controlled_4seeds_1000/) —
  CSV/JSON, график, история поиска и рецепты выбранных признаков.
- [tests/](tests/) — тесты алгоритма и временных признаков.
